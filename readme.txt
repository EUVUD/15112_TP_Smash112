1. Project Title and Description:
The name of the term project is “Smash112” which is a platform fighting game. This is a multiplayer game that enables two players to control characters in the game to fight against each other. The game will begin with a page that lets the player choose between multiplayer mode and ai mode. Then, the player will enter a page that enables them to choose the character and fighting field. After this, players will enter an interface instructing on how to play the game. 

When players proceed to the actual fighting, there will be a health bar on each side of the laptop screen telling them how many life points their character has. Players can use the attacking ability and the defending ability of their characters to knock out the other side or defend the attack from the other player. When one player’s health bar first reaches zero. The game is over and the word game over will show up on the screen. After this page, the players will have the choice to restart the whole game. In the AI mode, using the behavior tree algorithm, the AI player will control the other character to play against the human player. The AI can perform regular attacks and shoot the bullet. It can also track the location of human players and keep approaching.

2.Run instruction
To run the project, you just need to use python to run the Game_Basics.py file. You only need cmu_graphics to run the file. Please ensure that the you keep graphics and src in the same folder so images can be accessed successfully.
